安全鎖

鎖定時，會寫入遊戲記憶體的五個項目（下壓力、引擎馬力、油量、胎壓、碰撞無車損）將被停用；其餘功能不受影響。解鎖需先閱讀並同意授權聲明。狀態保存在本機，重啟後依然有效。

畫質

比遊戲的最低畫質再低一階：直接覆寫 Scalability.ini 的 [ShadowQuality@0] 等群組，逐項關掉陰影、體積霧、反射、泛光、動態模糊、環境光遮蔽、抗鋸齒。

寫入 Scalability.ini 與 Engine.ini，改前會備份；必須完全退出 ACC 再重新啟動才生效。

協議與來源

本軟體不連網、不收集、不上傳任何資料；全部設定僅保存在本機。

賽段時長讀自遊戲自己寫出的 race.ini；單圈時間與每圈油耗來自本機執行的疊加層（它直接讀 shared memory：iBestTime / iLastTime / completedLaps，並在每次過圈時依油量差測出油耗），所以圈數與建議加油無需手填。欄位語意取自官方 shared memory 結構定義與下列專案；計時、圈數與油量公式為本專案自行實作，未複製它們的程式碼，僅參考其公開的結構定義與演算法思路。下列名稱與著作權歸各自作者所有。
