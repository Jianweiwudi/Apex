## 项目通读（Apex / ACC 工具）

- 用户目标：先全面理解项目，之后要做**优化 + 加新功能**。
- 架构已确认（四进程）：
  - `Apex.exe` = C# WebView2 外壳，加载 `ui/index.html`（file://），通过 `window.chrome.webview` postMessage 收发 JSON status/命令；**完整版宿主的源码不在仓库里**（仓库只有 `tools/apex_lite_host.cs` 只读版源码，`tools/make_public.py` 用它编译 Apex Lite）。
  - `grip/apex_grip_server.py` = 2713 行、纯 stdlib 的 HTTP 服务，127.0.0.1:7798。负责：轮胎抓地曲线扫描/写入、碰撞车损、片头替换与视频转码（ffmpeg）、画质 ini 覆写、叠加层拉起、自动闪灯/干扰后车。
  - `ApexOverlay.ps1` = 1551 行 PowerShell + GDI+ 分层窗口（UpdateLayeredWindow），127.0.0.1:7799 控制通道（裸 TcpListener），80ms 数据 tick + 40ms 淡入淡出 timer。
  - ACC 进程：共享内存 `Local\acpmf_graphics/physics/static` 只读；进程内存读写走 ctypes ReadProcessMemory/WriteProcessMemory。
- 关键数据契约：`/status`（grip）、`/apex/state`（overlay）、宿主 `{type:"status"}` 包。
- 已知可优化点（待用户选方向）：
  1. 7798/7799 都是 `Access-Control-Allow-Origin: *` 且无 token → 任意网页可驱动本工具（含 `/quit`）。安全风险。
  2. 完整版宿主无源码，Apex.exe 是预编译产物 → 不可复现构建。
  3. README 与实际 HUD 不符：README 写「檔位、速度、G 值」，`Draw-Hud` 实际只画 0-100 / 100-200 / 合计 + 赛段 / 油量 / 圈速。
  4. 前端 5335 行单文件，多个独立 setInterval（700/1000/2000/3000/4000ms）轮询，无构建步骤。
  5. `ApexOverlay.ps1` 1356 与 1449 行重复声明 `$script:timer`（死代码）。
  6. 后端 `shared()` 每次调用都 OpenFileMapping/MapViewOfFile/Unmap/Close，25Hz 循环下 syscall 偏多（可缓存视图）。
  7. 抓地力定位靠全内存签名扫描（5–15s），无指针链/模块偏移缓存。

## 新功能：HUD 摩擦圆（已完成）

用户需求：读遥测实时显示摩擦圆，并显示「踏板 + 方向盘输入」落在圆上的哪个位置。

- 全部改动在 `ApexOverlay.ps1`（+398 行），**不碰 `Apex.exe`、不写游戏内存**，纯读 `acpmf_physics`。
- 新增读取偏移（`Read-Game`）：`gas`@4、`brake`@8、`steerAngle`@24、`accG[3]`@44/48/52。
- 显示：实际 G 点（按使用率绿/琥珀/红）、最近 2.4s 轨迹（逐段 alpha 渐隐）、峰值十字（按 `car|track` 持久化）、输入点空心环 + 虚线连线。
- **关键物理决策**：输入点的横向需求用运动学 `a_lat = v²·δ / (L·9.81)`，L 固定 2.70m；**不能**把转向角直接归一化映射到圆上（100km/h 时 0.1rad 会被算成 18%，实际车已在 90%）。纵向按实测最大加速/刹车 G 分别缩放（GT3 刹车约 2.5g、加速约 1.2g）。
- 圆半径自动跟随：`max(1.4, min(3.2, peak*1.08))`，0.06 系数缓动；峰值 >6g 视为撞车毛刺丢弃。
- 布局：`Get-Layout` 高度 202 → 344，圆直径 132 在左、读数 5 行在右。
- 静态圆环/十字/轴标签用 `Get-GBase` 按 scale 缓存成位图（同 `Get-Chrome` 思路），轨迹画笔按 alpha 桶缓存。
- 托盘新增：转向输入模式（自动/弧度/归一化）、翻转横轴、翻转纵轴——因为 `accG` 符号与 `steerAngle` 单位无法离线确认。
- 转向模式 auto 判定：观测到 |steer|>1.05 即判定为归一化，否则按弧度。
- 验证方式：`ApexOverlay.ps1 -Shot out.png -Demo`（demo 已加合成 G 轨迹），并用 PIL 按像素质心校验点位与 `g/radius` 比例一致。
- 文档同步：`ui/index.html` 三语 `ov.show`、`README.md` 功能表（顺带修正了 README 里 HUD「檔位/速度/G 值」的过时描述）。
- 遗留：`accG` 轴向与 `steerAngle` 单位需真机确认；若不对，用托盘开关修正，不要改代码。
